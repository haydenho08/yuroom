**Subject:** Request to use classroom timetable data for a free student study-space app

Hello,

My name is Hayden Ho, and I'm a first-year Software Engineering student at York. I'm building
a free, non-commercial web app called YURoom that helps students find an empty classroom to
study in. It shows which rooms have no class scheduled right now and how long they'll stay free.

Before using any timetable data, I wanted to ask for permission. The York website terms require
written consent to reuse its content, and the York Courses website blocks automated access, so I
haven't collected anything.

I'm asking for one of the following:

1. **A periodic export** (e.g. CSV, once per term or nightly) of scheduled class meetings with only
   these fields: term, building, room, day of week, start time, end time or duration, and the
   meeting's start/end dates. No course, instructor, or enrolment information is needed. **Or**
2. **Permission to download the public timetable once per day**, with a clearly identified
   "YURoom student project" client, at a rate you're comfortable with.

To address safety and privacy, YURoom would only ever show availability, such as "Room 1006:
booked 10:00–11:30, free until 2:30". It would not show course codes, instructors, or who is in
a room. It collects no personal information. It would carry the notice "Student-built, not
affiliated with York University" and wouldn't use York's name, logo or branding beyond
identifying campus buildings.

I'm happy to follow any conditions you set (attribution, update frequency, removing specific
rooms or buildings, or a review before launch). If someone else at York owns this data, I'd be
grateful if you could forward this message or point me to them.

Thank you for your time,

Hayden Ho
